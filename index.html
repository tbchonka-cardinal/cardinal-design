Cardinality Design Reference

Cardinal Design System v6.0.0

A layered heritage-parchment visual language with Stripe-grade mechanics: warm off-white canvas, crisp white surfaces held by hairline rings and two-tint shadows, lapis chrome, and a single brass accent that always means "actionable." Type is Garamond for display over the system UI sans (tabular figures for data), with Source Code Pro reserved for code. Five type sizes, a 4px spacing grid, 6px controls inside 12px containers, and 150ms motion on background and shadow only. v6 adds the dark scope: one class, .cds-dark, that swings the neutral ramp to a warm near-black and lifts brass and lapis to their light tiers.

Dark scope

Put .cds-dark on any element and every color role under it rewires onto the warm dark ramp. Nothing else moves: same spacing, same radii, same 1px ring, same type, same 150ms motion. Brass stays the only actionable color and lapis stays the chrome; only their lightness shifts, so a dark surface reads as the same system rather than a second one. Scope it to one card for a dark card on a light page, or to <body> for a whole app. Every pair below clears WCAG AA in docs/superpowers/tools/contrast.py.
